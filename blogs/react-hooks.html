Introducción a React Hooks

20 de Enero, 2023 8 min de lectura

Hola, soy Juan Sebastián Velásquez, desarrollador frontend especializado en React. Hoy quiero compartir contigo una de las características que más ha transformado mi forma de trabajar con React: los Hooks. Como desarrollador que ha trabajado tanto con componentes de clase como funcionales, te puedo decir que los Hooks son un cambio de paradigma que vale la pena dominar.

¿Qué son los React Hooks?

Cuando empecé con React allá por 2019, la mayoría de componentes con estado requerían clases. Pero desde la versión 16.8, los Hooks nos permiten usar estado y otras características de React sin escribir una clase. En esencia, los Hooks son funciones especiales que te permiten "enganchar" funcionalidades de React en componentes funcionales.

¿Por qué los prefiero?

En mis proyectos personales y profesionales, he encontrado que los Hooks ofrecen varias ventajas:

  • Menos código repetitivo: No necesitas el boilerplate de las clases
  • Lógica más organizada: Puedes separar preocupaciones por funcionalidad en lugar de por métodos del ciclo de vida
  • Reutilización de lógica: Con Custom Hooks puedes encapsular y compartir lógica entre componentes
  • Mejor legibilidad: El flujo es más lineal y fácil de seguir

Los Hooks esenciales que uso a diario

useState - Mi hook fundamental

Este es el hook que más utilizo para manejar el estado local en mis componentes. Aquí un ejemplo de cómo lo implemento: 

import React, { useState } from 'react';

function Contador() {
  const [contador, setContador] = useState(0); // Valor inicial

  return (
    <div>
      <p>Has hecho clic {contador} veces</p>
      <button onClick={() => setContador(contador + 1)}>
        Incrementar
      </button>
    </div>
  );
}

useEffect - Para efectos secundarios

Lo uso constantemente para operaciones asíncronas, suscripciones o manipulación del DOM. Este es un patrón que aplico frecuentemente: 

import React, { useState, useEffect } from 'react';

function DatosUsuario({ userId }) {
  const [usuario, setUsuario] = useState(null);
  
  useEffect(() => {
    // Este efecto se ejecuta al montar y cuando userId cambia
    const fetchData = async () => {
      const response = await fetch(`/api/usuarios/${userId}`);
      setUsuario(await response.json());
    };
    
    fetchData();
    
    // Función de limpieza
    return () => {
      // Cancelar solicitudes pendientes si es necesario
    };
  }, [userId]); // Dependencia

  return (
    <div>
      {usuario ? (
        <h2>{usuario.nombre}</h2>
      ) : (
        <p>Cargando...</p>
      )}
    </div>
  );
}

useRef - Referencias persistentes

Particularmente útil cuando necesito acceder directamente a elementos del DOM o mantener valores entre renderizados: 

function AutoFocusInput() {
  const inputRef = useRef(null);
  
  useEffect(() => {
    // Enfoque automático al montar
    inputRef.current.focus();
  }, []);
  
  return <input ref={inputRef} type="text" />;
}

Consejos desde mi experiencia

Después de trabajar con Hooks en múltiples proyectos, estos son mis tips personales:

  1. Crea tus propios Hooks: Si repites lógica en varios componentes, abstracta en un custom hook
  2. Usa el linter de React Hooks: Te ayuda a seguir las reglas básicas de los hooks
  3. Divide efectos complejos: Mejor múltiples useEffect pequeños que uno gigante
  4. Optimiza con useCallback y useMemo: Pero solo cuando realmente notes problemas de rendimiento

Mi conclusión

Los React Hooks han cambiado completamente mi forma de construir interfaces. Aunque al principio tuve que ajustar mi mentalidad, hoy no puedo imaginar trabajar sin ellos. La combinación de simplicidad y poder que ofrecen me permite crear componentes más limpios, mantenibles y reutilizables.
